Welcome to Nulang! This tutorial covers language basics, local actors, and effect handlers. Multi-node distribution and durable workflow features are experimental; this tutorial does not establish production readiness.

## 1. Installation

Install a checksummed, platform-specific release binary using the [Installation](/getting-started/installation/) guide. Verify its dependencies on your system and confirm the CLI is on your `PATH`. Building from source is an alternative for contributors and unsupported systems.

```bash
nulang --version
nulang --repl
```

**Browser playground:** the [playground](/playground/) runs a restricted WebAssembly Core subset. The actor examples below require the native runtime. Examples from current documentation may differ from older tagged release behavior; use a compatible release or source build.

## 2. Hello, World!

Nulang uses **algebraic effects** for I/O. Print to the console with `perform IO.print`:

```nulang
perform IO.print("Hello, Nulang!")
```

Run it:

```bash
nulang --eval 'perform IO.print("Hello, Nulang!")'
```

Or start the REPL and type interactively:

```bash
nulang --repl
nulang> perform IO.print("Hello, Nulang!")
```

## 3. Variables and Functions

Bind values with `let` and define functions with `fn`:

```nulang
let x = 42
let greeting = "Hello"

fn add(a: Int, b: Int) -> Int {
    a + b
}

perform IO.print(perform Int.to_string(add(x, 8)))
```

Closures capture their environment:

```nulang
let base = 10
let add_base = fn(x) { x + base }
perform IO.print(perform Int.to_string(add_base(5)))  // 15
```

## 4. Types and Pattern Matching

Nulang has Hindley-Milner type inference — types are usually optional. Declare custom variant types and match on them:

```nulang
type Option[T] = Some(T) | None

fn unwrap_or(opt: Option[Int], default: Int) -> Int {
    match opt with {
        | Some(x) => x
        | None => default
    }
}

let present = Some(42)
let absent = None
perform IO.print(perform Int.to_string(unwrap_or(present, 0)))  // 42
perform IO.print(perform Int.to_string(unwrap_or(absent, 99)))  // 99
```

Pattern matching supports guards, nested patterns, records, and wildcards:

```nulang
type Color = Red | Green | Blue

fn describe(c: Color) -> String {
    match c with {
        | Red => "warm"
        | Green => "natural"
        | Blue => "cool"
    }
}

fn classify(n: Int) -> String {
    match n with {
        | x if x < 0 => "negative"
        | 0 => "zero"
        | _ => "positive"
    }
}
```

## 5. Actors

Actors are the core concurrency primitive. Each actor has private state and a set of named behaviors:

```nulang
actor Counter {
    state count: Int = 0

    behavior inc() {
        self.count = self.count + 1
    }

    behavior get() { self.count }
}
```

Spawn an actor, call behaviors with `ask`, or fire-and-forget with `send`:

```nulang
actor Counter {
    state count: Int = 0
    behavior inc() { self.count = self.count + 1 }
    behavior get() { self.count }
}
let counter = spawn Counter {}
let result = ask counter get()       // 0
ask counter inc()
ask counter inc()
let result2 = ask counter get()
perform IO.print(perform Int.to_string(result2))  // 2
```

Actors can link together for fault tolerance, register names in the global registry, and monitor each other's lifecycle:

```nulang
actor Worker {
    behavior start(name: String) {
        perform Actor.register(name)
        perform IO.print(name + " registered")
    }
    behavior work() {
        perform Actor.exit(0)  // normal shutdown
    }
}
```

See the [Actor Model](/actors/overview/) and [Supervision Trees](/actors/supervision/) for local actors and failure containment; [Distribution & Clustering](/actors/distribution/) is experimental.

## 6. Algebraic Effects

Effects are Nulang's mechanism for side-effect management. The compiler tracks which effects each function may perform, and handlers intercept those effects at runtime:

```nulang
effect Logger {
    log: (String) -> Unit
}

fn greet(name: String) {
    perform Logger.log("greeting " + name)
    perform IO.print("Hello, " + name)
}

handle greet("World") {
    | Logger.log(msg) resume => {
        perform IO.print("[LOG] " + msg)
    }
}
```

Built-in effects include `IO`, `Timer`, `Signal`, `Inference` (LLM), `Actor`, and `Otp` (supervisors). See the [Standard Library](/stdlib/overview/) for the complete reference.
