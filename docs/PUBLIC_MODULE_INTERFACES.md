# Experimental public module interfaces

The compiler-owned module interface sidecar lives in
`src/public_interface.rs` and can be generated by
`public_interface::interface_for_hir(&typed_hir)`.

It is intentionally **not** a new source syntax, bytecode format, executable
ABI, import resolver, package version policy, or stable wire protocol.

## Current contract

- Accept an already-checked typed HIR module from its declaring source.
- Include public functions, aliases, opaque aliases, records, and variants.
- Respect explicit export lists in nested `module` declarations.
- Sort public declarations by qualified path before computing the digest.
- Hash types with the existing compiler semantic encoder, which normalizes
  inference variable / region / skolem IDs.
- Include function parameter names, explicit/dictionary argument split,
  effects, capabilities, return types, and generic arity.
- Exclude private declarations, implementation bodies, and source spans.
- Fail if a nested module explicitly exports a declaration kind whose
  semantics this first sidecar does not model (actors, effects, databases).
  Silent omission would incorrectly imply that its digest covers that API.

The JSON exposes `schema_version`, `module`, `exports`, and `api_digest`.
Each export has `path`, `kind`, a readable `signature`, and a deterministic
`signature_digest`. Readable signatures are for tooling/UI, **not** for
fingerprint validation.

## Deliberate limitations

The current public HIR can contain flattened imported declarations. Until
the resolver's declaration-provenance work is integrated, callers **must**
supply the defining module's HIR rather than treating a flattened importer
as a canonical defining-module API. Do not use this digest as a correctness
gate for incremental dependency invalidation yet.

Actor behavior protocols, resource authority and schema/migration metadata
require compiler-owned contract descriptors before they can be part of a
complete interface digest. Treat explicit unsupported exports as errors;
do not infer they are irrelevant.

There is no CLI emission flag or on-disk cache integration in this slice.
The sidecar and public function remain experimental and are not promised to
be compatible across schema versions.

## Verification

```bash
cargo test public_interface::tests --lib
cargo fmt --all -- --check
cargo test --lib
```

Also require the repository's normal bytecode, native, WASM and minimal
feature/profile jobs before promotion. A passing format check alone does
not establish a trustworthy public-interface contract.

## Promotion path

1. Land and validate import-origin correctness (PR #1627).
2. Pin full exported actor-protocol, effect/authority and migration metadata.
3. Add canonical declaration origin to the typed HIR interface derivation.
4. Add a versioned JSON emission command and an exact-head reproducibility
   fixture that invokes the real compiler twice with fresh inference IDs.
5. Only then consume the API digest for dependency recompilation decisions.
