Parse a JSON string into a JsonValue.

Pure-Nulang recursive-descent parser. Handles all JSON value types:

## `json`

#### `parse`

```nulang
pub fn parse(json: String) -> JsonValue
```

Parse a JSON string into a JsonValue.

Pure-Nulang recursive-descent parser. Handles all JSON value types:
null, true, false, numbers (int/float/scientific), strings (with
\", \\, \/, \b, \f, \n, \r, \t, \uXXXX escapes), arrays, and
nested objects.

Trailing whitespace and extra content after the first value are
ignored. Empty or whitespace-only input returns JsonNull.

Example (verified by `scripts/verify_doc_examples.sh`):
```nulang
// Round-trip a JSON object through parse + stringify.
import stdlib::json

fn main() {
let v = parse("{\"a\": 1, \"b\": [true, null]}")
let s = stringify(v)
perform IO.print("round-trip: " + s)
}
```

Convert a JsonValue back to a JSON string.

Full fidelity for all types including nested arrays and objects.
