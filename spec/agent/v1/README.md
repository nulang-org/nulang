# NLAP v1 — NuLang Agent Protocol

Version: 1.0.0

Shared between NuLang Agent Runtime (OSS) and NuLang AI Cloud (managed).

- `domain.schema.json` — Goal, Task, Conversation
- `events.schema.json` — NLAP event envelope
- `execution.schema.json` — agent sessions/runs, task attempts, workspace leases, anchored changes, tool calls, checkpoints, artifacts, and evidence
