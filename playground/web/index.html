    About this playground
    

      This page loads nulang_playground.wasm, a WebAssembly build of the
      real Nulang compiler front-end (lexer → parser → typechecker → MIR → bytecode)
      plus the CoreVM interpreter — the same source files the native
      nulang run --backend core-vm path uses. Feature support matches the
      CoreVM: pure functional code, effects like IO.print, and the frozen
      Core subset. Actors, networking, FFI, and the JIT are native-only.
    

    

      Source & build instructions:
      github.com/nulang-org/nulang/playground
