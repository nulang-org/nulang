    What runs here?
    

      The playground supports the frozen Core subset, pure functions, closures,
      recursion, and effects such as IO.print. Actors, networking,
      FFI, and JIT execution require the native runtime.
    

  


  

    How this playground is built
    

      nulang_playground.wasm contains the real Nulang lexer, parser,
      typechecker, MIR lowering, bytecode generator, and CoreVM interpreter from
      the main repository. It does not use a separate toy parser.
